# 图书馆自动预约 v0.19.0

本次更新加入国内下载与应用内更新，并补齐主流安卓品牌的权限引导。

## 新功能

- 新增应用内更新：启动后自动检查新版本，下载完成后校验 SHA-256、包名、版本号和签名，再交给系统安装器确认安装。
- 国内用户可从 Gitee 发布页下载；GitHub 同版本同步发布，作为备用下载。
- 按小米、华为、荣耀、OPPO、vivo、三星、魅族等品牌显示对应的后台权限设置路径。
- 权限页新增应用更新卡片，可手动检查、下载、取消或打开发布页。

## 说明

- 更新不会在预约任务运行中、任务启动前 15 分钟、登录页或首次权限引导期间执行。
- 应用不会静默安装，也不会自动提交预约；安装时由系统弹出确认。
- 从 v0.18.0 升级到 v0.19.0 需要先卸载旧版再安装，因为旧版使用临时调试签名，无法覆盖安装。卸载会清除本地的账号、任务、记录和权限设置；学校系统中的预约记录不受影响。此后版本可直接覆盖升级并保留数据。
