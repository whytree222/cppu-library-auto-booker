# 图书馆自动预约 v0.20.2

修复 WebVPN 统一认证提交后，应用提前停止认证回跳、持续提示未登录的问题。

## 修复与改进

- 补全学校统一认证返回 WebVPN 的确认步骤，只向已核对的固定学校登录入口发送一次 GET，不重复发送账号密码。
- 修正仅含查询参数的相对跳转解析，并正确处理不应发送到服务器的 URL 片段；外部地址与异常回跳继续停止。
- 检查系统是否真正接受学校会话 Cookie，避免写入失败后仍继续登录。
- 未登录时支持重新获取可填写的认证表单；只读状态检查保留仍有效且尚未提交的验证码，不复用已提交或过期的表单。
- 登录未完成时用弹窗显示具体原因，验证码不可用时明确说明，不再只显示空白图片区域。
- 保持原有直接预约、00:58 一次性定时、十分钟等待及预约提交后不换线路、不重发的保护。

## 升级与验证

- 使用现有正式签名；从 v0.19.x、v0.20.0 或 v0.20.1 可覆盖升级，正式版原有数据保留。
- 用户已于 2026-10-27 确认 E 调试版登录问题解决；新正式签名包、五天会话有效期、锁屏和隔夜预约仍需验证。
- 调试版与正式版的数据相互独立。请在更新正式版后重新登录 WebVPN，确认正常后再移除调试版。
- 统一认证验证码仍由用户在应用内手动输入；自动重试或自动识别未重新开启。
