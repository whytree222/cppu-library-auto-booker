# 图书馆自动预约 v0.20.0

本次更新正式加入学校 WebVPN 校外备用与可选的自动重登，校园网夜间断联或在校外时，仍可尝试完成已排队的预约。

## 新增

- **直连优先、单向切换**：仅当提交预约前发生 DNS、连接、超时或网关故障时，才切换到学校 WebVPN；切换后本批次不再自动切回。
- **可选的两层自动重登**：WebVPN 默认手动网页登录。可在“自动登录账号设置”中分别保存统一认证与 WebVPN 图书馆账号，密码只在本机使用 AES/GCM + AndroidKeyStore 加密；会话过期时自动重登。
- **本机离线验证码识别**：验证码使用随 APK 打包的模型在本机识别，只接受 4 位数字且置信度不低于 0.70；图片和账号不会上传，也可关闭自动识别并手动输入。
- **有界重试**：自动登录共用 90 秒期限，最多提交 3 次、明确验证码失效后重开 2 次；预约批次内最多自动重登一次。
- **提交保护不变**：一旦进入提交阶段，结果不明、网络中断或会话过期都只停止并提示核对学校记录，不换线路、不重新登录、不重复提交。
- 00:58 一次性精确闹钟、直接预约快照、候选座位冲突重试和失败分类规则保持不变。

## 说明

- 安装包包含离线验证码模型，体积约 51 MB，仅支持 arm64-v8a / armeabi-v7a 手机。
- 从 v0.19.x 可直接覆盖升级，本机账号、任务、设置和记录会保留。
- 从 v0.16.x 或更早版本首次升级仍会一次性清理旧版 WebVPN 自动登录数据；如需自动重登，请在新版中重新明确保存两套账号。
- WebVPN 与统一认证会话能否整夜保持有效由学校系统决定，尚未完成真机隔夜验证；自动重登不能绕过学校主动失效、额外验证或风控。
- 本项目不是学校官方应用，请遵守学校图书馆的预约规则和学校相关规定。
