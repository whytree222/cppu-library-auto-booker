# 图书馆自动预约 v0.20.1

WebVPN 登录改为应用原生表单。在应用内完成统一认证和图书馆两层登录，验证码仅手动输入。

## 更新内容

- 在应用中填写统一认证学工号、密码和四位数字验证码，支持换图及学校“五天内自动登录”选项。
- 统一认证通过后，在应用中填写另一套图书馆账号密码；学校确认两层会话有效后再返回主界面。
- 可选择在本机分别加密记住两套账号密码；密码、验证码和动态表单参数不会写入日志或界面恢复数据。
- 停用统一认证的验证码自动识别与网页自动点击。统一认证过期后，需要打开应用内登录并手动补输验证码；已有 WebVPN 外层会话有效时可继续后台预约，仅图书馆内层过期时保留已授权的内层自动重登。
- 验证码绑定当前会话，旧表单、会话变化、重复点击和提交结果不明时不会自动重复提交。复用已有登录会话不会把未经本轮验证的保存密码标为已验证。
- 保留 00:58 一次性预约、直接预约、十分钟等待及预约提交后不换线路、不重发的保护。

## 升级与验证

- 使用现有正式签名，从 v0.19.x / v0.20.0 可覆盖升级；本机设置和任务保留。
- 学校“五天内自动登录”的实际有效期由学校决定，不保证隔夜免操作。
- 已完成本地模拟测试与构建；尚未完成真机两层登录、锁屏和隔夜预约验证。
- 调试包与正式包分开安装；本发布资产为正式包，不是此前的调试 APK。
