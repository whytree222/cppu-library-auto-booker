# 图书馆自动预约 v0.20.3

修复通过 WebVPN 预约时，登录检查已通过却停在“正在选择使用日”、最终只显示任务超时的问题。

## 修复与改进

- 修正代理页面的表单地址比较，避免同一地址反复改写；表单观察器不再由自身修改重复触发，防止网页计时器和日期弹窗被阻塞。
- 增加选日、选时段流程的脚本异常提示，不记录账号、密码、验证码或会话参数。
- 为查找阅览室、选择日期、选择时段和进入座位图增加每阶段 25 秒的独立超时保护；即使网页脚本停止响应，也能说明停在哪一步。
- 保留直连优先、提交前网络故障才单向切换 WebVPN，以及提交结果不明时停止、不重发的保护。
- 保留直接预约、00:58 一次性定时、最多十分钟等待开放，以及房间、日期、时段和座位的精确校验。

## 升级与验证

- 使用既有正式签名，可覆盖升级 v0.19.x 和 v0.20.0–v0.20.2，保留正式版账号、设置、任务和记录。
- 用户已于 2026-10-28 反馈选日修复调试包可用；新正式签名包、五天会话、锁屏与隔夜预约仍需验证。
- 调试版和正式版的数据独立。请在正式版内确认 WebVPN 登录有效，确认使用正常后再移除调试版。
- WebVPN 继续使用原生应用表单、手动验证码和可选本机加密记住两套账号；统一认证过期需补输验证码，仅图书馆内层保留自动重登。
