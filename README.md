# 警察大学图书馆自动预约（Android）

本项目面向校内预约站点 `http://mlib.cppu.edu.cn` 的过刊阅览室。可以前一晚按优先级输入座位号，选择今天或明天以及七个固定时段中的连续 1–4 段，再设置下一次放号时间。应用届时启动前台任务，依输入顺序查找可预约座位并尝试预约。

## 安装

从 [GitHub Releases](https://github.com/whytree222/cppu-library-auto-booker/releases) 下载 `app-debug.apk`，安装到 Android 8.0 或更新版本的手机。这是调试签名的侧载版。手机运行任务时必须连接能访问校内站点的网络。

## 使用

1. 连接校园局域网，打开应用，点“打开预约系统 / 登录”，在学校网页自行登录。登录成功并跳转后会自动返回应用；也可点网页上方“返回应用”。
2. 在“座位号”输入框每行填一个编号，第一行优先。例如 `G015A`。最多 10 个，重复编号会自动去重。
3. 填写实际放号时间，从七个固定时段中选择连续的 1–4 段。保持“演练模式”开启，点“立即演练”，确认应用能依次进入过刊阅览室、选日、选时段和识别座位。演练会导航到座位图，但不会提交预约。
4. 演练成功后关闭“演练模式”，开启“下次放号时运行一次”，保存任务并授予精确闹钟及通知权限。

预约任务只运行一次，运行后自动关闭。当前每次任务只处理一笔（最多四个连续时段）；超过四段需要分笔安排，自动分笔尚未实现。若首选座位不可预约，会寻找下一座位；若提交后收到明确失败提示，只有确认先前座位已取消选中才会继续尝试下一项。若无法判断提交结果，应用会停止并提示到学校系统核对，避免重复提交。用户仍需按学校规定完成签到。

## 当前适配限制

已确认登录入口是 `/login`、选择流程是 `/selectreadingroom`、座位图是 `/multireadingroomtablelist`。用户提供的开发者工具截图显示过刊阅览室卡片调用 `roomonclick('26')`，使用日由 `selectusedaybuttonclick(...)` 选择，时段由学校网页提供的复选框表单提交；应用不保存或自行生成网页签名参数。座位元素以完整编号为 `id`（例如 `G015A`），用 `available` / `unavailable` 类标记状态。最终按钮调用 `layoutBespeak()`。这些结构来自截图；完整导航和提交结果仍需在校内网络上演练及现场验证。如果任一步找不到或状态不符，应用会停止，不会猜测位置。不能保证放号瞬间一定抢到座位。

学校登录页目前使用 HTTP。页面对密码进行 Base64 编码，但没有 TLS 传输保护；请只在可信的校园网络中登录。应用不保存用户名或密码，只复用本机 WebView 的登录 Cookie。不要在公开 Issue 中上传 Cookie、Token、学号或密码。

## 构建

GitHub Actions 使用 JDK 17、Android SDK 35 和 Gradle 8.9 构建 `assembleDebug`，成功后将 APK 放入 Actions Artifact 和 GitHub Release。本机安装相同工具后，也可运行 `gradle assembleDebug`。输出位于 `app/build/outputs/apk/debug/app-debug.apk`。仓库不包含登录凭据、签名密钥或 Cookie。
