# 警察大学图书馆自动预约（Android）

本项目面向校内预约站点 `http://mlib.cppu.edu.cn`。用户可以在前一晚进入一楼座位图，依次记录最多 10 个想要的位置，再设置下一次放号时间。应用在该时间启动前台任务，依优先顺序查找仍显示为绿色的座位并尝试预约。

## 安装

在 GitHub Releases 下载 `app-debug.apk`，安装到 Android 8.0 或更新版本的手机。此 APK 是调试签名的侧载版本。手机需要在运行时连接能访问校内站点的网络。

## 使用

1. 打开应用，点“打开预约系统 / 登录”，在学校网页中自行登录。
2. 点“在一楼座位图中选择”，按网页流程进入一楼座位图。
3. 点“开启位置录入”，依次点击想要的位置，先点的优先。录入层会截获点击，不会把点击发给学校网页。灰色座位也可以提前记录；到放号时只有变为绿色的座位才会尝试预约。
4. 设置实际放号时间和预约时段。保持“演练模式”开启，先点“立即演练”确认至少一个候选位置被识别。
5. 演练成功后再关闭“演练模式”，开启“下次放号时运行一次”，保存任务并授予精确闹钟及通知权限。

预约任务只运行一次，运行后自动关闭。用户需要按学校规定完成签到。

## 当前适配限制

我们已确认登录入口是 `/login`、一楼座位列表路由是 `/multireadingroomtablelist`，也知道绿色图标代表可预约。站点在未登录请求下只提供登录页，因此目前尚未拿到登录后座位图的 DOM 或接口响应。座位录入脚本会在手机上记录元素路径和屏幕位置；预约脚本仅在能从元素样式确认绿色时才点击，并且只有识别到明确的网页成功提示才报告成功。若页面结构变化或采用图片精灵显示状态，演练会失败，需要根据实际页面继续适配。不能保证放号瞬间一定抢到座位。

学校登录页目前使用 HTTP。页面对密码进行 Base64 编码，但没有 TLS 传输保护；请在可信的校园网络中登录。应用不保存用户名或密码，只复用本机 WebView 的登录 Cookie。不要在公开 Issue 中上传 Cookie、Token、学号或密码。

## 构建

仓库的 GitHub Actions 工作流使用 JDK 17、Android SDK 35 和 Gradle 8.9 构建 `assembleDebug`，成功后将 APK 放入 Actions Artifact 和 GitHub Release。

本机也可安装 JDK 17、Android SDK 35 与 Gradle 8.9，然后运行：

```sh
gradle assembleDebug
```

输出位于 `app/build/outputs/apk/debug/app-debug.apk`。本项目没有提交 `local.properties`、密码、签名密钥或登录 Cookie。
